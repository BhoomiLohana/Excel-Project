📊 Vrinda Store Data Analysis – Excel Dashboard
📝 Project Overview

The Vrinda Store Data Analysis Dashboard is an interactive Excel-based analytics project designed to analyze sales and order performance for an e-commerce clothing store.
The dashboard provides clear business insights using KPIs, charts, and slicers, helping stakeholders understand trends, customer behavior, and operational efficiency.

This project demonstrates strong skills in Excel data analysis, dashboard design, and business intelligence.

🎯 Objectives

Analyze annual sales and order data

Identify top-performing sales channels and states

Understand customer demographics (Age & Gender)

Track order fulfillment status

Create an interactive and visually appealing dashboard

📌 Key Features

📈 Total Sales & Total Orders KPIs

🛍 Orders by Sales Channel (Amazon, Flipkart, Myntra, etc.)

👩‍🦰👨 Sales Distribution by Gender

🎂 Age vs Gender Sales Analysis

📅 Monthly Sales Trend

📦 Order Status Analysis (Delivered, Cancelled, Returned, Refunded)

🌍 Top 5 States by Sales

🔍 Key Insights

👩 Women contribute ~64% of total sales

🛒 Amazon and Myntra are the top-performing channels

📦 Over 90% orders are successfully delivered

🌍 Maharashtra leads in state-wise sales

👥 Adult age group generates the highest revenue

📉 Sales peak in early months and gradually decline towards year-end
