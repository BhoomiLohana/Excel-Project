# 📊 Vrinda Store Annual Sales Analysis – Excel Dashboard

## 📌 Description
This project is a comprehensive **Excel-based data analysis and dashboard** created for **Vrinda Store**, an e-commerce fashion retailer.  
The dashboard analyzes **annual sales and order data (2022)** and presents meaningful business insights using interactive visuals and KPIs.

The project focuses on **data cleaning, pivot table analysis, and professional dashboard design** to support data-driven decision-making.

---

## 🎯 Project Objectives
- Analyze annual sales performance
- Track total revenue and order volume
- Identify top-performing sales channels
- Understand customer demographics (Age & Gender)
- Analyze order fulfillment and delivery status
- Visualize monthly sales trends
- Create an interactive and user-friendly Excel dashboard

## 📊 Key Metrics (KPIs)
- **Total Sales:** 21.17 Million
- **Total Orders:** 31,047
- **Delivery Rate:** 92%
- **Return / Cancel Rate:** ~8%

---

## 📈 Dashboard Components
- **KPI Cards:** Total Sales, Total Orders
- **Orders vs Sales Trend**
- **Orders by Channel:** Amazon, Flipkart, Myntra, Meesho, Ajio, Others
- **Monthly Sales Trend**
- **Age vs Gender Sales Analysis**
- **Sales Contribution by Gender**
- **Order Status Distribution**
- **Top 5 States by Sales**
- **Interactive Filters (Slicers):**
  - Month
  - Category
  - Channel

---

## 🔍 Key Business Insights
- Women customers contribute approximately **64% of total sales**
- **Amazon and Myntra** are the leading sales channels
- More than **90% of orders are successfully delivered**
- **Maharashtra** generates the highest revenue among all states
- **Adult age group** contributes the maximum sales volume
- Sales peak during the early months and gradually decline towards the end of the year

## 🚀 How to Use
1. Download the Excel file from this repository
2. Open the file in **Microsoft Excel**
3. Use the slicers on the dashboard to filter:
   - Month-wise data
   - Product category
   - Sales channel
4. Analyze KPIs and charts to extract insights
